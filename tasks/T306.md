## Spécification (décidée, ne pas réinterpréter)
Reproduire `write_banksel` et l'initialisation de MAME :
- `pub fn initial_pbank_base(p_len:usize)->u32 { if p_len > 0x100000 { 0x100000 } else { 0 } }` (ligne 1306).
- `pub fn banksel(base:&mut u32, p_len:usize, data:u16)` : si `p_len <= 0x100000` : ne rien changer ; sinon `bank = (data & 7) as usize` ; si `(bank+1)*0x100000 >= p_len` alors `bank = 0` ; `*base = ((bank+1)*0x100000) as u32`.
- Brancher dans `Bus68k::write16` (T302) : toute écriture (mot ou octet, n'importe quelle voie) dans `0x2FFFF0..=0x2FFFFF` appelle `banksel(&mut self.pbank_base, self.cart_p.len(), data)` ; `Bus68k::new` initialise `pbank_base` avec `initial_pbank_base`.
Les écritures dans le reste de $200000-$2FFFFF sont ignorées (sauf protections, P7).
