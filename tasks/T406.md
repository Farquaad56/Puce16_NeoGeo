```rust
pub struct LspcRoms<'a> { pub c:&'a [u8], pub s_cart:&'a [u8], pub s_bios:&'a [u8], pub lo:&'a [u8], pub use_cart_fix:bool, pub fix_bank:FixBankType, pub pal:&'a Palette }
/// Rend la ligne `v` (= update_partial(v) -> screen_update) dans fb.
pub fn render_line(vram:&[u16], roms:&LspcRoms, anim_counter:u8, anim_disabled:bool, v:u16, fb:&mut Framebuffer);
impl Lspc {
  pub fn advance_render(&mut self, to:u64, roms:&LspcRoms, fb:&mut Framebuffer);   // while time<to { if let Some(line)=self.advance(to) { self.on_line_start(line,roms,fb) } }
  fn on_line_start(&mut self, line:u16, roms:&LspcRoms, fb:&mut Framebuffer);
}
```
`on_line_start(line)` (= `sprite_line_timer_callback`) : `if line != 0 { render_line(&self.vram, roms, self.anim_counter, self.anim_disabled, line-1, fb) }` PUIS `parse_sprites(&mut self.vram, line)`.
`render_line(v)` : si `v` ∉ [16, 239] ne rien faire ; sinon `row = [u32;320]` rempli de `roms.pal.backdrop()` ; `draw_sprites_line(vram, roms.c, roms.lo, roms.pal.pens_base(), anim_counter, anim_disabled, v, &mut row)` ; `draw_fixed_line(vram, gfx, roms.use_cart_fix, roms.fix_bank, roms.pal.pens_base(), v, &mut row)` (gfx = `s_cart` si `use_cart_fix` sinon `s_bios`) ; copier `row` dans `fb.pixels[(v-16)*320 ..]`.
**Oracle fourni (déjà généré par Claude, ne pas régénérer)** : `tests-data/scenes/<scène>/` pour fix_std, sprites_plain, sprites_zoom_chain, fix_garou, fix_kof2000. Fichiers : `vram.bin` (0x8800 u16 LE), `pens.bin` (0x1000 u32 LE = `pal.pens[0..0x1000]` ; le backdrop est donc `pens[0xFFF]`), `c.bin`, `s.bin`, `lo.bin`, `meta.txt` (lignes « clé valeur » : anim_counter, anim_disabled 0/1, fix_bank 0=Std 1=Garou 2=Kof2000, from_cart 0/1), `expected.raw` (320×224 u32 LE 0x00RRGGBB, produit par `tools/ref_render.py`, port Python indépendant de MAME).
Test `tests/scenes.rs` : pour chaque scène : charger les fichiers ; `Palette::new()` puis copier `pens.bin` dans `pal.pens[0..0x1000]` ; `s_cart = s_bios = s.bin` ; `use_cart_fix = from_cart==1` ; `fb = Framebuffer::new()` ; boucle `for line in 0..264u16 { if line != 0 { render_line(&vram,&roms,anim_counter,anim_disabled,line-1,&mut fb) } ; parse_sprites(&mut vram, line) }` ; comparer `fb.pixels` à `expected.raw` pixel par pixel (message : scène, x, y, attendu, obtenu).
