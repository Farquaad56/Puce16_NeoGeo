## Spécification (décidée, ne pas réinterpréter)
**Principe** (DÉCISION figée) : le 68000 est MAÎTRE et avance **une horloge à la fois** (`Cpu::step_clock`). `now` = temps en mclk au DÉBUT de l'horloge courante ; `Bus::on_tick` (appelé une fois par horloge, après les accès de cette horloge) fait `now += 2`. Un accès `Bus::read` (horloge 3 du cycle) ou `Bus::write` (horloge 2) est donc daté `now` à l'instant de l'appel. Les autres composants sont « rattrapés » (catch-up) jusqu'à `now` : LSPC, Z80 (au T-state près : plus de dépassement d'instruction), YM2610, RTC, watchdog.
`struct Host68k<'a> { m: &'a mut MachineParts }` (références disjointes aux champs de Machine hors `cpu`) implémente `puce_m68k::bus::Bus` :
- `read(addr,_fc,_uds,_lds)` : `catch_up()` PUIS `bus.read16(addr)` ; `write(addr,_fc,uds,lds,data)` : `catch_up()`, `bus.write16(addr,data,uds,lds)`, puis `after_write`.
- `wait_clocks(addr,write)` : `waits::bus_wait(addr,write) as u8` (T601).
- `ipl()` : `lspc.advance_render(now,..)` puis `lspc.irq_level()` (échantillonné par le CPU aux frontières d'instruction).
- `int_ack(_level)` : `None` (autovecteur ; les IRQ Neo Geo s'acquittent par écriture à $3C000C).
- `on_tick(_pins)` : `now += 2`.
`catch_up()` : (1) `lspc.advance_render(now, &roms, &mut fb)` ; (2) `z80_run_until(now)` ; (3) `sound.ym.advance(now)` ; (4) RTC `rtc.advance(delta)` ; (5) `wd.advance(delta)` (si vrai => `reset_request=true`).
`z80_run_until(t)` : `while sound.time + 6 <= t { sound.tick(&mut z80) }` (T305).
`after_write(addr,..)` : si `pending_sound_cmd` pris dans Io : `sound.host_write_cmd(v)` ; si octet à `0x3A00xx` : recopier les q du latch vers `bus.vectors_from_cart`, `sound.use_cart`, `pal.bank`, `backup.unlocked` ; si `io.watchdog_kick` : `wd.kick()`.
`run_frame(&mut self)` : `target = frame_start + 405_504` ; `while now < target { match cpu.step_clock(&mut host) { None => host.now += 2, Some(_) => {} } ; if reset_request { self.reset() } }` ; `catch_up()` final ; `frame_start = target` ; `audio.extend(sound.ym.samples.drain(..))`. (`None` = CPU arrêté ou aucune horloge exécutée : le temps passe quand même ; si `cpu.is_halted()`, noter « double faute » dans le journal de debug.)
`finish_instruction(&mut self)` : `while !cpu.at_instruction_boundary() { step_clock }` (utilisé avant un savestate et avant un instantané de débogueur).

## Tests à écrire (valeurs exactes)
- Programme 68k minimal en RAM (`NOP` en boucle `60 FC` après `4E 71`) : après run_frame, `now >= 405_504` et lspc.time() >= 405_504.
- Chaque appel de `on_tick` fait avancer `now` de 2 (compteur de test).
- Écriture octet 0x320000 par le 68k => `sound.cmd_pending==true` immédiatement et `sound.cmd` correct.
- Z80 au T-state : après un `catch_up` à `now = 6000`, `sound.time == 6000` (jamais plus) quand le Z80 exécute des NOP depuis un M1 de test.
- Écriture latch 0x3A0003 (q1=1) => `bus.vectors_from_cart==true`.
- Watchdog : sans kick, reset_request après 3 244 030 mclk (test avec Watchdog::advance directement).
