## Spécification (décidée, ne pas réinterpréter)
Constantes : `MCLK_PER_PIXEL=4`, `MCLK_PER_LINE=1536` (384 px), `LINES=264`, `VBSTART=240`, `VSSTART=256`, `VBLANK_IRQ_OFFSET=58` (56+2 mclk), `RELOAD_OFFSET=1146` (mclk).
```rust
impl Lspc {
  pub fn time(&self)->u64;                                   // mclk depuis le reset
  pub fn irq_level(&self)->u8;                               // 3 si irq3, sinon 2 si raster, sinon 1 si vblank, sinon 0
  pub fn advance(&mut self, to_mclk:u64)->Option<u16>;       // traite les événements ≤ to_mclk dans l'ordre chronologique ; S'ARRÊTE au premier début de ligne (time = cet instant) et retourne Some(vpos de la ligne qui commence) ; sinon time=to_mclk et None
}
```
État ajouté : `time:u64`, `irq3:bool` (vrai au reset), `raster:bool`, `vblank:bool`, `timer_deadline:Option<u64>`, `t_vbl_irq:u64`, `t_reload:u64`, `t_anim:u64`, `next_line:u64` (initialisés : `t_vbl_irq = 240*1536 + 58`, `t_reload = 240*1536 + 1146`, `t_anim = 256*1536`, `next_line = 0`). `vpos = ((time / 1536) % 264) as u16` (mis à jour dans `self.vpos`).
Événements (comportement EXACT de MAME) ; à égalité de date l'ordre est : vblank_irq, reload, timer d'affichage, animation, début de ligne :
1. **vblank_irq** à `t_vbl_irq` : `vblank=true` ; `t_vbl_irq += 405_504`.
2. **reload (autoload vblank)** à `t_reload` : si `irq2_ctrl & 0x40` : `timer_deadline = Some(t_reload + (display_counter as u64 + 1) * 4)` ; `t_reload += 405_504`.
3. **timer d'affichage** à `timer_deadline` : si `irq2_ctrl & 0x10` : `raster=true` ; si `irq2_ctrl & 0x80` : `timer_deadline = Some(deadline + (display_counter as u64 + 1) * 4)` sinon `None`.
4. **animation** à `t_anim` : `auto_animation_tick()` (T400) ; `t_anim += 405_504`.
5. **début de ligne** à `next_line` : retourne `Some(vpos)` ; `next_line += 1536`.
`set_timer_low(d)` (T400) : met à jour `display_counter` bas puis `if irq2_ctrl & 0x20 { timer_deadline = Some(time + (display_counter as u64 + 1) * 4) }`. `acknowledge(d)` : `if d&1 {irq3=false}; if d&2 {raster=false}; if d&4 {vblank=false}`.
Remarque : `time` reste le temps du dernier `advance` ; le Machine appelle toujours `advance` jusqu'à `now` AVANT tout accès registre, donc `time == now` au moment des écritures.

## Tests à écrire (valeurs exactes)
- Au reset irq_level()==3 ; acknowledge(1) => 0.
- Boucle de test `run_to(t)` = `while let Some(_) = advance(t) {}` : run_to(240*1536+57) => vblank=false ; run_to(240*1536+58) => irq_level()==1 ; acknowledge(4) => 0 ; run_to(240*1536+58+405504) => 1 de nouveau.
- Timer : irq2_ctrl=0x30 (enable+relatif), display_counter=99 via set_timer_low à time=1000 => deadline 1000+400=1400 : run_to(1399) => raster=false ; run_to(1400) => irq_level()==2 ; sans bit 7 pas de répétition (timer_deadline None).
- Bit 7 (0xB0) : après l'événement, deadline = ancienne + 400 : raster ré-armé (acknowledge(2) puis run_to suivant => de nouveau 2).
- Autoload (irq2_ctrl=0x50, counter=9999) : à 240*1536+1146 le timer est armé à +40 000 mclk.
- advance retourne Some(0) à time=0, Some(1) à 1536, Some(263) à 263*1536 puis Some(0) à 264*1536.
- auto_animation : anim_counter augmente d'un pas (vitesse 0) à time=256*1536 et à 256*1536+405504.
