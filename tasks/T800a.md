## Spécification (décidée, ne pas réinterpréter)
Dépendances : `cargo add -p ng-gui eframe crossbeam-channel` (+ `ng-core`, `ng-cart`, `ng-common` en path déjà présents).
```rust
pub enum Cmd { Load{ game:String }, Reset, Pause(bool), Inputs{ p1:PadState, p2:PadState, sys:SystemButtons }, Quit }
pub struct FrameMsg { pub pixels: Vec<u32> /*320*224, 0x00RRGGBB*/, pub frame:u64, pub fps:f32 }
pub fn spawn(cfg: Config) -> (crossbeam_channel::Sender<Cmd>, crossbeam_channel::Receiver<FrameMsg>);   // thread émulation
```
`emu_thread` : boucle : `try_recv` toutes les commandes ; si une machine existe et non pause : `machine.set_inputs(..)`, `machine.run_frame()`, envoyer `FrameMsg` (canal borné à 2 : `try_send`, jeter si plein), puis attendre jusqu'à la date cible `t0 + frame*405504/24_000_000 s` (`std::time::Instant` UNIQUEMENT dans ce thread/GUI, jamais dans ng-core) ; pas de machine : dormir 16 ms. `Cmd::Load` : `load_machine(&cfg, &game)` ; erreur => envoyer via un second canal `Receiver<String>` (message affiché en rouge).
`app.rs` : `struct App { tx, rx, err_rx, texture:Option<egui::TextureHandle>, last:Option<FrameMsg>, paused:bool, inputs... }` implémente `eframe::App::update` : consomme `rx` (garder le dernier), convertit `pixels` en `egui::ColorImage` (`Color32::from_rgb((p>>16)&255,(p>>8)&255,p&255)`), `ctx.load_texture("fb", img, TextureOptions::NEAREST)` à la première trame puis `tex.set(img, NEAREST)` ; `egui::CentralPanel` : `ui.image` à l'échelle entière maximale conservant le ratio 40:28 (ratio 4:3 affiché : pixel aspect non traité, noté QUESTIONS) ; `ctx.request_repaint()` à chaque update. `main.rs` : `eframe::run_native("Puce16 NeoGeo", NativeOptions::default(), Box::new(|_| Ok(Box::new(App::new()))))` (adapter la signature à la version d'eframe installée : consulter `cargo doc` local, pas le web).
