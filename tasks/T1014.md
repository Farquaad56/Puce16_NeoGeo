## Spécification (décidée, ne pas réinterpréter)
vliner (cartouche `rom_vliner`) et jockeygp (`cmc50_jockeygp`) ont 8 Kio de RAM sur la cartouche, visibles de $200000 à $201FFF (lecture/écriture mot, miroir selon `neogeo.cpp` l.1526), **non volatile** (NVRAM).
- `Protection` gagne `cart_ram: bool` (true pour ces 2 jeux). `Machine` possède `cart_ram: Vec<u8>` (0x2000 octets, vide sinon) ; mapping 68000 : lecture/écriture mot dans la fenêtre. Elle doit être incluse dans `save_state`/`load_state` (changer la version du format et le test de compatibilité si besoin).
- Persistance : fichier `saves_dir/<jeu>.cartram` (8192 octets), chargé au démarrage s'il existe, écrit à `save_machine` (même mécanisme que la memcard T903).
- Entrées spéciales : lire `INPUT_PORTS_START( vliner )` / `jockeygp` dans `neogeo.cpp` ; ajouter à `ng-bus/io.rs` les bits/ports correspondants (mappés dans la GUI par T804c : ajouter seulement les `Action` manquantes si le jeu en exige ; sinon les entrées existantes suffisent — noter le choix dans STATE.md).
