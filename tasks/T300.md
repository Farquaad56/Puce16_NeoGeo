```rust
pub enum CartError { Io(std::io::Error), Zip(String), MissingFile(String), BadCrc{ file:String, expected:u32, got:u32 }, TooBig{ file:String } }
pub struct Cart { pub def: &'static CartDef, pub p: Vec<u8>, pub s: Vec<u8>, pub m: Vec<u8>, pub m_crypt: Vec<u8>, pub v: Vec<u8>, pub c: Vec<u8> }
pub enum Source { Zip(zip::ZipArchive<std::fs::File>), Dir(std::path::PathBuf) }
impl Source { pub fn open(path:&Path)->Result<Source,CartError>; pub fn read(&mut self, name:&str)->Result<Vec<u8>,CartError>; }
pub fn load_cart(path:&Path, def:&'static CartDef, check_crc:bool)->Result<Cart,CartError>;
pub fn find_def(name:&str)->Option<&'static CartDef>;   // cherche dans ALL_CARTS par def.name
```
Algorithme de `load_cart` (EXACT) :
1. Allouer `p=vec![0;sizes.p]`, `s=vec![0;sizes.s]`, `v=vec![0;sizes.v]`, `c=vec![0;sizes.c]`, `m=vec![if sizes.m_crypt>0 {0xFF} else {0}; sizes.m]`, `m_crypt=vec![0;sizes.m_crypt]`.
2. Pour chaque `part` de `def.parts`, dans l'ordre : `data = source.read(part.file)` (mettre en cache le dernier fichier lu) ; si `check_crc` et `crc32_bytes(&data) != part.crc` => `BadCrc` (le CRC est celui du FICHIER ENTIER) ; `slice = &data[src_off .. src_off+size]` (erreur MissingFile si trop court) ; écrire dans la région selon `load` :
   - `Plain` : `dst[dest .. dest+size] = slice`.
   - `WordSwap` : pour k in 0..size/2 : `dst[dest+2k] = slice[2k+1]; dst[dest+2k+1] = slice[2k]`.
   - `Byte` : pour i in 0..size : `dst[dest + 2*i] = slice[i]`.
   - `Word32Swap` : pour k in 0..size/2 : `dst[dest+4k] = slice[2k+1]; dst[dest+4k+1] = slice[2k]`.
   Si l'écriture dépasse la région : `TooBig`.
3. Si `def.m1_reload = Some((dest,size))` : `m.copy_within(0..size, dest)` (ROM_RELOAD).
`Source::read` pour un zip : cherche l'entrée par nom (insensible à la casse) ; si absente => `MissingFile`. Pour un dossier : `dir.join(name)`.

## Tests à écrire (valeurs exactes)
- Test avec un `CartDef` fabriqué (Box::leak) : P WordSwap : fichier [0x12,0x34,0x56,0x78] -> P[0..4] = [0x34,0x12,0x78,0x56].
- Byte : c1=[1,2], c2=[9,8] avec dest 0 et 1 -> C[0..4]=[1,9,2,8].
- Word32Swap : p1=[0x11,0x22,0x33,0x44] dest 0 ; p2=[0xAA,0xBB,0xCC,0xDD] dest 2 -> P[0..8]=[0x22,0x11,0xBB,0xAA,0x44,0x33,0xDD,0xCC].

- M reload : m1_reload Some((8,4)) avec M[0..4]=[1,2,3,4] -> M[8..12]=[1,2,3,4].
- CRC faux avec check_crc=true -> Err(BadCrc).
- Source Dir et Source Zip (zip écrit dans le test avec zip::ZipWriter) donnent les mêmes octets.
