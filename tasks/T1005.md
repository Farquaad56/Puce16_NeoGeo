## Spécification (décidée, ne pas réinterpréter)
Sept jeux dont seules les ROM graphiques (C) et la ROM fixe (S) sont chiffrées par la puce CMC42 ; aucune protection au runtime (`RuntimeProt::None`), banc standard.
Pour chacun (MAME `cmc.cpp`, `decrypt_all` : `cmc42_gfx_decrypt(C, clé)` puis `sfix_decrypt(C -> S)`) :

| jeu | clé gfx | banc fixe |
|---|---|---|
| zupapa | 0xBD | Garou (type 1) |
| ganryu | 0x07 | Garou (type 1) |
| s1945p | 0x05 | Garou (type 1) |
| preisle2 | 0x9F | Garou (type 1) |
| bangbead | 0xF8 | Garou (type 1) |
| nitd | 0xFF | Garou (type 1) |
| sengoku3 | 0xFE | Garou (type 1) |

- `gen_tables.py` : fabrique `PROT_<JEU>` = `Protection { cmc: Cmc::C42, gfx_key: <clé>, sfix_decrypt: true, fix_bank: FixBank::Garou, ..N }` et ajoute les 7 jeux au `CATALOGUE`.
- Région S : MAME déclare `ROM_REGION(0x80000, "cslot1:fixed")` + `ROM_FILL` : `sizes.s = 0x80000`, aucune partie S (le générateur ignore déjà `ROM_FILL`). La M1 et les V ne sont pas chiffrées.
- `cmc42_gfx_decrypt` doit accepter la taille C de chaque jeu (lire `sizes.c` dans `defs.rs`). Si une taille déclenche une panique ou un cas non géré : corriger la fonction dans `cmc.rs` d'après `prot_cmc.cpp` (cas de taille), jamais la contourner.
