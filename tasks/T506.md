## Spécification (décidée, ne pas réinterpréter)
`pub fn mix_ym(o:[i16;3])->[f32;2]` (mélange du MAME neogeo) : `l = (0.98*o[0] as f32 + 0.84*o[2] as f32)/32768.0` ; `r = (0.98*o[1] as f32 + 0.84*o[2] as f32)/32768.0` (o = [FM gauche, FM droite, SSG] déjà clampés en i16 ; pas de clamp après).
YM2610 produit un échantillon tous les 432 mclk (55 555,56 Hz à 24 MHz ; 24 167 829/432 en AES). `struct AudioResampler { pub fn new(src_hz:f64, dst_hz:u32); pub fn push(&mut self, s:[f32;2]); pub fn pop_into(&mut self, out:&mut Vec<f32>) /*stéréo entrelacé*/ }` : interpolation linéaire, état fractionnaire en f64. Aucun accès au temps système ; déterministe.

## Tests à écrire (valeurs exactes)
- mix_ym([32767,0,0]) == [0.98*32767/32768, 0.0] à 1e-6 près ; mix_ym([0,0,10000]) == [0.84*10000/32768 ; même valeur à droite].
- src_hz=48000,dst=48000 : sortie == entrée.
- src 24000 -> dst 48000 : sortie de 2N−1 échantillons, les impairs sont les moyennes des voisins.
- push de 55 556 échantillons à 55 555,56 Hz vers 48 000 Hz => 48 000 ± 1 échantillons.
