## Spécification (décidée, ne pas réinterpréter)
```rust
pub struct Machine {
    pub cpu: puce_m68k::cpu::Cpu, pub z80: puce_z80::Cpu,
    pub bus: Bus68k,                       // contient io, lspc (Lspc), palette, backup, memcard, port
    pub sound: SoundBoard<YmAdapter>,      // Z80 + YM
    pub lspc: Lspc, pub pal: Palette,      // (références partagées avec le Bus via Rc<RefCell<..>> : voir ci-dessous)
    pub cart: Cart, pub bios: Bios, pub model: Model,
    pub now: u64,                          // temps 68000 en mclk depuis le reset
    pub frame_start: u64, pub wd: Watchdog,
    pub fb: Framebuffer, pub audio: Vec<[f32;2]>,    // échantillons YM produits pendant la trame
}
impl Machine { pub fn new(cart:Cart, bios:Bios, model:Model)->Machine; pub fn reset(&mut self); }
```
**Partage Lspc/Palette/Io entre le Bus et la Machine** (DÉCISION) : `Rc<RefCell<Lspc>>`, `Rc<RefCell<Palette>>`, `Rc<RefCell<Io>>`, `Rc<RefCell<BackupRam>>` ; le Bus reçoit des adaptateurs `struct Shared<T>(Rc<RefCell<T>>)` qui implémentent `Device` en déléguant (créer `shared.rs` dans ng-core). Pas de threads dans le cœur.
`YmAdapter` (ym_adapter.rs) : implémente `ng_bus::Ym` ET `ng_ym2610::YmfmInterface` : possède `ym:Ym2610`, `adpcm_a_rom:Vec<u8>` (région V de la cartouche ; même ROM pour A et B pour les jeux Metal Slug), `ym_time:u64` (mclk), `timer_deadline:[Option<u64>;2]`, `irq:bool`, `busy_end:u64`, `samples:Vec<[f32;2]>` (déjà mélangés par `mix_ym`, T506), `next_sample:u64`.
 - `advance(mclk)` : boucle : prochaine échéance = min(timer_deadline[0], timer_deadline[1], next_sample) ; si ≤ mclk : si timer : `ym.engine_timer_expired(tnum)` (timer_deadline[tnum]=None) ; si sample : `ym.generate(&mut out /*[[i32;3]]*/,1)`, clamp de chaque voie en i16, `samples.push(mix_ym(..))` et `next_sample += 432` ; répéter ; à la fin `ym_time=mclk`.
 - YmfmInterface : `set_timer(tnum, duration_in_clocks)` : `deadline = if duration<0 {None} else {Some(ym_time + duration as u64 * 3)}` (1 horloge YM = 3 mclk) ; `update_irq(b)` : `irq=b` ; `set_busy_end(c)` : `busy_end = ym_time + c*3` ; `is_busy()` : `ym_time < busy_end` ; `external_read(AdpcmA|AdpcmB, addr)` : `adpcm_a_rom[addr & mask]` (0 si hors taille).
**Construction** (`Machine::new`) : BIOS dans `bus.bios` ; `bus.cart_p = cart.p` ; Z80 : `sound.sm1 = bios.sm1`, `sound.m1 = cart.m` ; Lspc roms prises à la demande dans `run_frame` ; `reset()` : `cpu = Cpu::new(); cpu.reset()` puis `finish_reset()` = `step_clock` jusqu'à la première frontière d'instruction (les vecteurs sont lus dans le BIOS car `vectors_from_cart=false` ; 40 horloges = 80 mclk, `now` compris) ; `z80 = puce_z80::Cpu::new(); z80.reset()` ; `sound.reset()` ; `lspc = Lspc::new()` (IRQ3 en attente) ; latch réinitialisé ; `now=0`.
