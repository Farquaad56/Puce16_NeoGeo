## Spécification (décidée, ne pas réinterpréter)
`pub struct Pvc { ram: [u16; 0x1000], bank: Option<u32> }` (RAM 8 Kio, mots) implémente `CartPort` pour `0x2FE000 <= a <= 0x2FFFFF` ; `o = (a - 0x2FE000) >> 1` (0..0xFFF).
- `read` : `Some(ram[o])`.
- `write(a, d, upper, lower)` : fusion `COMBINE_DATA` : octets selon upper/lower ; puis si `o == 0xFF0` : `unpack_color` ; si `o` ∈ {0xFF4, 0xFF5} : `pack_color` ; puis si `o >= 0xFF8` : `bank = Some(get_bank_base())`. Retourne true.
- `unpack_color` : `pen = ram[0xFF0]` ; `b = ((pen&0x000F)<<1) | ((pen&0x1000)>>12)` ; `g = ((pen&0x00F0)>>3) | ((pen&0x2000)>>13)` ; `r = ((pen&0x0F00)>>7) | ((pen&0x4000)>>14)` ; `s = (pen&0x8000)>>15` ; `ram[0xFF1] = (g<<8)|b` ; `ram[0xFF2] = (s<<8)|r`.
- `pack_color` : `gb = ram[0xFF4]`, `sr = ram[0xFF5]` ; `ram[0xFF6] = ((gb&0x001E)>>1) | ((gb&0x1E00)>>5) | ((sr&0x001E)<<7) | ((gb&0x0001)<<12) | ((gb&0x0100)<<5) | ((sr&0x0001)<<14) | ((sr&0x0100)<<7)` (u16, troncature comme C++).
- `get_bank_base` : `bankaddress = (ram[0xFF8]>>8) as u32 | (ram[0xFF9] as u32)<<8` ; `ram[0xFF8] = (ram[0xFF8] & 0xFE00) | 0x00A0` ; `ram[0xFF9] &= 0x7FFF` ; retourne `bankaddress + 0x100000`.
- `take_bank` : `bank.take()`.
