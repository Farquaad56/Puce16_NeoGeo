## Spécification (décidée, ne pas réinterpréter)
Remplir les onglets Vidéo, Palette et Sprites de la fenêtre T805b. **Vidéo** : registres LSPC (`offset`, `modulo`, `irq2_ctrl`, `display_counter`, `anim_counter`, vpos) en tableau ; image de la couche fix 320x256 avec **grille de tuiles 8x8 optionnelle** et survol : au survol d'une tuile, afficher `(col,ligne) code=XXX pal=N` ; case « zone visible » dessinant le cadre 320x224 (lignes 16-239). **Palette** : sélecteur de page (0-31) et de banque ; grille 16x16 de pastilles (taille 14 px), survol = `index : mot hex → RGB` ; clic sur une pastille = copie `#RRGGBB` dans le presse-papiers ; ligne distincte pour la couleur de fond (pen $FFF) et indication de l'entrée sombre/ombre (bit 15). **Sprites** : tableau triable (colonnes N, Tuile, Pal, Flip, Zoom H/V, X, Y, Taille, Chaîne) ne montrant que les sprites actifs (chaînage inclus, comme `active_sprites`), filtre « sur la ligne Y = … » (utilise `sprite_on_scanline`) et compteur « n sprites actifs, m sur la ligne ». Décodage SCB1-4 en fonctions pures (`decode_scb2` : zoom H = bits 8-11, zoom V = bits 0-7 ; `decode_scb4` : X = bits 7-15 signé 9 bits). Toutes les fonctions d'affichage de texte sont pures et testées ; largeur fixe, police monospace, nombres hexadécimaux en majuscules.

- `decode_scb2(0x0FFF)` : zoom H = 0xF, zoom V = 0xFF.
- `decode_scb4(0x1234 << 0)` : X = 0x24 ; `decode_scb4(0xFF80)` : X = -1 (signé 9 bits).
- `tile_at(px, py) -> (col,ligne)` : (319,255) -> (39,31) ; survol hors image -> None.
- `pen_label(0x10, 0x0F00)` : `10 : 0F00 → #…` avec RVB calculé par `word_color`.
- Filtre ligne : un sprite de taille 2 en Y=0x20 est sur la ligne 0x30 mais pas sur 0x50.
