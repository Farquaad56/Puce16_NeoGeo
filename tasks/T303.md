## Spécification (décidée, ne pas réinterpréter)
**Latch 74HC259** (`latch.rs`) : écriture OCTET IMPAIR à `0x3A0000..0x3A001F` (miroir jusqu'à $3BFFFF) ; sortie `n = (addr >> 1) & 7`, valeur `v = (addr >> 4) & 1` (la donnée écrite est ignorée). `struct SystemLatch { pub q: [bool; 8] }` (tout à false au reset). Sémantique : q0 SHADOW ; q1 vecteurs cartouche (REG_SWPROM) ; q2,q3,q4 verrous carte mémoire (stockés, sans effet) ; q5 CRTFIX (1 = S ROM + M1 de la cartouche ; 0 = sfix/sm1 du BIOS) ; q6 SRAM déverrouillée ; q7 banc de palette 1. Accesseurs : `shadow()`, `use_cart_vectors()`, `use_cart_fix_audio()`, `sram_unlocked()`, `palette_bank()`.
**E/S** (`io.rs`, `struct Io` implémente `Device`) — valeurs MVS (octet haut = adresse paire), ENTIÈREMENT déterminées par MAME :
- Lecture `(a>>16)&0xFE == 0x30` : si `a & 0x80 == 0` (REG_P1CNT/DIPSW, $300000) : `(pad1.bits << 8) | dipsw` avec `dipsw = 0xFF` par défaut (champ `pub dipsw:u8`) ; si `a & 0x80 != 0` ($300080 TEST) : `0xFF00 | 0x40 | (if test_pressed {0} else {0x80})` = `0xFFC0` repos.
- Lecture `0x32` ($320000) : `(sound_reply << 8) | status_a` avec `status_a` bits : b0 coin1, b1 coin2, b2 service, b3 coin3, b4 coin4 (tous ACTIFS-BAS : 1 = relâché), b5 = 0 (MVS 1 slot), b6 = TP du RTC, b7 = DATA OUT du RTC (fournis par `rtc: Rc<RefCell<..>>` ou valeurs poussées par T304 : `pub rtc_tp:bool, pub rtc_data_out:bool`).
- Lecture `0x34` ($340000) : `(pad2.bits << 8) | 0xFF`.
- Lecture `0x38` ($380000) : `0x00FF | ((system.bits & 0x0F) as u16) << 8 | 0x7000 | 0x8000` (0x7000 = pas de carte mémoire ; 0x8000 = MVS ; AES : voir T307). Rappel : bits 8-11 = Start1, Select1, Start2, Select2 (actifs-bas).
- Écriture octet à `0x300001` (mirror) : `watchdog_kick = true`. 
- Écriture octet à `0x320000` (addr&1==0) : `sound_command(byte)` : `pub pending_sound_cmd: Option<u8>` consommé par le Machine (T600).
- Écritures à `0x380000..0x3800FF` octet IMPAIR : `off = (a >> 1) & 0x78` : 0x00 sélection manette (ignorée), 0x08 `card_bank = v & 7`, 0x10 slot (ignoré), 0x18 latch LED (ignoré), 0x20 données LED (ignoré), 0x28 RTC : `rtc_din = v&1; rtc_clk = (v>>1)&1; rtc_stb = (v>>2)&1` (exposés en champs `pub`, lus par T304), 0x30/0x70 compteurs/verrous de pièces (ignorés).
- Écritures `0x3A0000-0x3BFFFF` -> latch. 
`Io` détient `pub pad:[PadState;2]`, `pub system:SystemButtons`, `pub test_pressed:bool`, `pub sound_reply:u8`, `pub watchdog_kick:bool`.
**Watchdog** (dans ng-bus/src/watchdog.rs) : `struct Watchdog { pub counter: u64 }` ; `kick()` met le compteur à 0 ; `fn advance(&mut self, mclk:u64)->bool` retourne true (=> RESET machine complet) quand `counter >= 3_244_030` (valeur MAME). Le reset est effectué par T600.
