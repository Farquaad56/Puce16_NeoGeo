## Spécification (décidée, ne pas réinterpréter)
```rust
pub enum FixBankType { Std, Garou, Kof2000 }
pub fn draw_fixed_line(vram:&[u16], gfx:&[u8], from_cart:bool, bank:FixBankType, pens:&[u32], vpos:u16, out:&mut [u32;320]);
```
Port 1:1 de `draw_fixed_layer(bitmap, scanline=vpos)` (vpos ∈ 16..239) : `addr_mask = gfx.len()-1` ; `banked = from_cart && addr_mask > 0x1FFFF` ; `video_data = 0x7000 | (vpos >> 3)` (indice dans `vram`) ; pour `bank==Garou && banked` construire `garouoffsets[34]` EXACTEMENT comme le C++ (boucle `while y<32` avec `k` pas de 2, lecture `vram[0x7500+k]==0x0200 && (vram[0x7580+k]&0xFF00)==0xFF00`) ; puis pour x in 0..40 : `cp = vram[video_data]` ; `code = cp & 0xFFF` ; si banked : Garou : `code += 0x1000 * (garouoffsets[((vpos>>3) - 2) & 31] ^ 3)` ; Kof2000 : `code += 0x1000 * ((((vram[0x7500 + (((vpos>>3)-1)&31) + 32*(x/6)] >> ((5 - (x%6))*2)) & 3)) ^ 3)` ; `gfx_offset = ((code << 5) | (vpos & 7)) & addr_mask` ; `char_pens = pens[((cp >> 12) << 4)..]` ; pour `off` dans `[0x10, 0x18, 0x00, 0x08]` : octet `d = gfx[gfx_offset + off]` ; pixel gauche : `if d & 0x0F != 0 { out[px] = char_pens[d & 0x0F] }` ; px+=1 ; pixel droit : `if d & 0xF0 != 0 { out[px] = char_pens[d >> 4] }` ; px+=1 ; `video_data += 0x20`. (`(y-2)&31` : arithmétique entière signée du C++ ; en Rust utiliser `((y as i32 - 2) & 31) as usize`.) Les pixels transparents ne modifient pas `out`.
