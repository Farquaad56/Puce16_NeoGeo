## Spécification (décidée, ne pas réinterpréter)
Dépendance : `cargo add -p ng-gui gilrs`. Table par défaut (clavier) : P1 — Haut=↑ Bas=↓ Gauche=← Droite=→, A=`Z`, B=`X`, C=`A`, D=`S` ; Start=`Enter`, Select=`RShift`. P2 : flèches=`I K J L`, A=`G`, B=`H`, C=`T`, D=`Y`, Start=`P`. Pièce 1 = `5`, Pièce 2 = `6`, Service = `9`, Test = `F2`. Format des bits : voir `PadState` (T001) : bits actifs-bas, ordre exact défini par T001 §PadState (utiliser les constantes, ne pas redéfinir). Manette : gilrs `Button::South=A, East=B, West=C, North=D, Start, Select`, croix + stick gauche (seuil 0,5). API : `struct InputState { pub fn update_keys(&mut self, ctx:&egui::Context); pub fn poll_gamepads(&mut self); pub fn pads(&self)->(PadState,PadState); pub fn system(&self)->SystemButtons; pub fn test(&self)->bool }`.
