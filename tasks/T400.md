## Spécification (décidée, ne pas réinterpréter)
```rust
pub struct Lspc {
    pub vram: Box<[u16; 0x8800]>,       // 0x0000-0x7FFF lente, 0x8000-0x87FF rapide ; index = adresse & 0x87FF
    offset: u16, read_buffer: u16, modulo: u16,
    pub anim_speed: u8, pub anim_disabled: bool, pub anim_counter: u8, anim_frame_counter: u8,
    pub irq2_ctrl: u16,                  // data & 0x00F0
    pub display_counter: u32,            // registre de reload du timer
    pub vpos: u16,                       // ligne MAME 0..263 (mis à jour par timing.rs)
    // + champs ajoutés par T401-T406 (timing, palette, rendu)
}
impl Lspc { pub fn new()->Self;
  pub fn read_reg(&mut self, offset:u32 /* mot 0..7 */, upper:bool, lower:bool) -> Option<u16>;   // None = non mappé (bus ouvert)
  pub fn write_reg(&mut self, offset:u32 /* mot 0..7 */, data:u16, upper:bool, lower:bool);
}
```
Règles EXACTES (neogeo_v.cpp l.228-272, neogeo_spr.cpp l.76-110) :
- `set_offset(d)`: `offset = if d & 0x8000 != 0 { d & 0x87FF } else { d }` ; `read_buffer = vram[offset & 0x87FF]`. (`vram[offset]` : si offset ≥ 0x8800 et < 0x8000 impossible : offset<0x8000 sinon masqué.)
- `get_data()` = read_buffer. `set_data(d)`: `vram[offset] = d` ; `set_offset((offset & 0x8000) | ((offset.wrapping_add(modulo)) & 0x7FFF))`.
- lecture registres : accès avec `lower && !upper` (octet bas seul) => `None`. Sinon offset 0 ou 1 (`$3C0000/$3C0002`) => `read_buffer` ; 2 => `modulo` ; 3 ($3C0006) => `get_video_control()` ; 4..7 => `read_buffer` (default du switch C++).
- écriture : si `lower && !upper` => ignorée ; si `upper && !lower` => `data = (data & 0xFF00) | (data >> 8)` ; puis `match offset { 0 => set_offset(data), 1 => set_data(data), 2 => modulo = data, 3 => set_video_control(data), 4 => display_counter = (display_counter & 0xFFFF) | (data as u32) << 16, 5 => (T401), 6 => (T401: acknowledge), 7 => {} }`. Les cas 4-6 appellent des méthodes de T401 : déclarer ici `fn set_timer_high(&mut self, d:u16)` (corps complet), `fn set_timer_low(&mut self, d:u16)` (corps: met à jour display_counter bas ; l'armement du timer est ajouté par T401), `fn acknowledge(&mut self, d:u16)` (corps vide, T401).
- `get_video_control()` : `v = vpos + 0x100 ; if v >= 0x200 { v -= 264 } ; (v << 7) | (anim_counter & 7)` (u16).
- `set_video_control(d)`: `anim_speed = (d >> 8) as u8 ; anim_disabled = (d & 8) != 0 ; irq2_ctrl = d & 0x00F0`.
- Auto-animation (appelée par T401 à vpos=256) : `fn auto_animation_tick(&mut self)` : `if anim_frame_counter == 0 { anim_frame_counter = anim_speed; anim_counter = anim_counter.wrapping_add(1) } else { anim_frame_counter -= 1 }`.

## Tests à écrire (valeurs exactes)
- offset=0x1234, modulo=1 : write_reg(1,0xBEEF,true,true) => vram[0x1234]==0xBEEF et l'offset interne devient 0x1235 (relire via write_reg(0,0x1235) puis read_reg(1)==vram[0x1235]).
- Zone rapide : write_reg(0,0x8001,..) ; write_reg(1,0x1111) => vram[0x8001]==0x1111, offset interne 0x8002 (bit 15 préservé).
- modulo=0xFFFF (−1) à l'adresse 0x0000 => l'incrément retombe sur 0x7FFF (masque 0x7FFF).
- read_reg(3) avec vpos=0, anim_counter=5 => ((0x100)<<7)|5 = 0x8005 ; avec vpos=263 : v=0x207-264=0x0FF → 0x7F85 (calculer et écrire la valeur attendue : 0x0FF<<7 = 0x7F80 | anim).
- Octet haut seul : write_reg(0, 0xAB00, true, false) => offset = 0xABAB & ... (0xABAB a bit 15 → 0x87FF & 0xABAB = 0x83AB).
- Octet bas seul : write_reg(0, 0x00FF, false, true) ne change rien ; read_reg(0,false,true) == None.
- auto_animation_tick : speed=2 : frame_counter 0 -> reload à 2, counter 1 ; puis ticks : fc 2->1, 1->0, 0->(reload, counter 2).
