## Spécification (décidée, ne pas réinterpréter)
sbp (bootleg) : cartouche `boot_sbp`. Deux mécanismes (portage exact de `sbp.cpp`) :
1. **Patch de la ROM P** à l'installation (`patch`) : `P16[0x2A6F8/2] = P16[0x2A6FA/2] = P16[0x2A6FC/2] = 0x4E71` ; `P16[0x3FF2D/2] = 0x7001` (mots 16 bits, ordre des mots du 68000 tel que dans `P` après chargement).
2. **Port runtime** sur la fenêtre cartouche : `read(offset)` = mot de P à `offset + 0x200/2` avec les bits permutés `bitswap<16>(orig, 11,10,9,8,15,14,13,12,3,2,1,0,7,6,5,4)`, SAUF si `0x200 + offset*2 == 0xD5E` (renvoie `orig` tel quel) ; `write` : ignore (consomme) les écritures de 0x4E75 ou 0xFFFF à l'adresse 0x1080, ignore aussi les autres (journaliser seulement en test).
- `ROM_IGNORE` dans `ROM_START( sbp )` : voir le source ; le générateur l'ignore, la taille de région vient du `ROM_REGION`. Vérifier que les parties du jeu chargent (T1003 sur `sbp`).
- `PDecrypt::Sbp` (patch), `RuntimeProt::Sbp` ; pas de CMC.

## Tests à écrire (valeurs exactes)
- Patch : sur un buffer P de zéros de taille `sizes.p` : octets [0x2A6F8..0x2A6FE] == `4E 71 4E 71 4E 71` et [0x3FF2C..0x3FF2E] == `70 01` en lecture mot 16 bits du 68000 (même convention d'octets que les autres tests P du crate : documenter laquelle) ; tout le reste == 0.
- Port : P avec mot[0x200/2 + 3] = 0xABCD -> `read(3) == Some(0xBADC)` (`bitswap<16>(0xABCD, 11,10,9,8,15,14,13,12,3,2,1,0,7,6,5,4)` : quartet haut = bits 11-8 de l'entrée, puis 15-12, puis 3-0, puis 7-4) ; `read` à l'offset correspondant à 0xD5E renvoie le mot brut.
- `make_port` renvoie `Some` pour `sbp`.
