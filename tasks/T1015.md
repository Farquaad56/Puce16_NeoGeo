## Spécification (décidée, ne pas réinterpréter)
Les 3 jeux de mahjong (machine MAME `neogeo_mj`, BIOS par défaut « japan ») se jouent avec le **panneau mahjong** (touches A-N, Kan, Pon, Chi, Ri-chi, Ron, Start, Select), pas avec le joystick.
- Ajouter `Controller` à `CartDef` (défaut `Joystick`) ; `Mahjong` pour ces 3 jeux (généré, avec une table `CONTROLLER` dans `gen_tables.py`).
- Émuler le protocole du panneau comme MAME (`neogeo_mj` : sélection de la rangée par le registre de sortie $380000 bits 0-2... lire `neogeo.cpp` : valeurs de rangée et mapping des bits ; reproduire exactement). Port 1 et 2 comme en MAME.
- GUI : quand le jeu est `Mahjong`, la fenêtre Contrôles affiche les 20 actions du panneau (mêmes mécanismes de sauvegarde `gui.toml`, section `[input]`, touches par défaut A-N sur les lettres du clavier, Pon = P, Chi = C, Kan = K, Ron = R, Ri-chi = I, Start = Entrée, Select = Maj gauche).
- Le BIOS « japan » est sélectionné automatiquement pour ces jeux s'il est disponible (sinon message dans la barre d'état).
