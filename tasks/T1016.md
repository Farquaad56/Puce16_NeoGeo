## Spécification (décidée, ne pas réinterpréter)
- `irrmaze` : trackball. Nécessite le BIOS spécial `236-bios.sp1` (présent DANS `irrmaze.zip`, région `mainbios`, CRC 0x853E6B96 « Asia MV1B 263 ») : la machine charge ce BIOS à la place du BIOS choisi quand le jeu est `Trackball` et que le fichier est dans le zip ; sinon, message d'avertissement et BIOS normal (BIOS Universe ≥ 2.2 acceptable : le jeu se joue au joystick).
- `popbounc` : molette (« dial », `neogeo_arc_edge_fixed "dial"`). 
- Protocole des deux contrôleurs : copier `INPUT_PORTS_START` et le connecteur d'entrée MAME (compteurs X/Y 8 bits incrémentés par le mouvement, lus sur les ports 1/2).
- GUI : le déplacement de la souris dans la zone de jeu alimente les compteurs (sensibilité réglable dans la fenêtre Contrôles, sauvegardée dans `gui.toml`) ; sans souris, les flèches simulent un mouvement constant.
