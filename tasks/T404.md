## Spécification (décidée, ne pas réinterpréter)
Constantes : `MAX_SPRITES_PER_SCREEN=381`, `MAX_SPRITES_PER_LINE=96`.
`pub fn sprite_on_scanline(scanline:i32, y:i32, rows:i32)->bool { rows==0 || rows>=0x20 || ((scanline - y) & 0x1FF) < rows*0x10 }`.
`pub fn parse_sprites(vram:&mut [u16], scanline:u16)` : `base = if scanline & 1 != 0 { 0x8680 } else { 0x8600 }` ; `y=0; rows=0; count=0; p=base` ; pour `n` de 0 à 380 : `yc = vram[0x8200 | n]` ; si `yc & 0x40 == 0` (non chaîné) : `y = 0x200 - (yc >> 7)` (i32) ; `rows = yc & 0x3F` ; si `rows==0` continue ; si `!sprite_on_scanline(scanline,y,rows)` continue ; `vram[p]=n ; p+=1 ; count+=1` ; si `count==96` break. Après la boucle : mettre à 0 `96 - count + 1` entrées à partir de `p` (`vram[p .. p + (96-count+1)] = 0`). (Écriture dans 0x8600..0x865F+1 ou 0x8680..; ne dépasse jamais 0x86FF.)
