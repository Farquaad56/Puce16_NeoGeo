## Spécification (décidée, ne pas réinterpréter)
```rust
pub trait Device { fn read(&mut self, addr:u32) -> u16;  fn write(&mut self, addr:u32, data:u16, upper:bool, lower:bool); }   // addr = adresse 24 bits paire
pub struct Bus68k {
    pub work_ram: Box<[u8; 0x10000]>,   // $100000-$10FFFF, miroir jusqu'à $1FFFFF
    pub bios: Vec<u8>,                  // 0x20000 octets big-endian
    pub cart_p: Vec<u8>,                // région P de la cartouche (peut être vide)
    pub vectors_from_cart: bool,        // latch Q1 (REG_SWPROM)
    pub pbank_base: u32,                // décalage dans cart_p de la fenêtre $200000 (T306)
    pub open_bus: u16,                  // valeur lue sur les zones non mappées (le Machine la met à jour)
    pub io: Box<dyn Device>,            // $300000-$3FFFFF hors LSPC (T303)
    pub lspc: Box<dyn Device>,          // $3C0000-$3C000F (T400)
    pub palette: Box<dyn Device>,       // $400000-$7FFFFF (T402)
    pub backup: Box<dyn Device>,        // $D00000-$DFFFFF (T304)
    pub memcard: Box<dyn Device>,       // $800000-$BFFFFF (T304)
    pub port: Option<Box<dyn CartPort>>, // protections de cartouche sur $200000-$2FFFFF (P7)
}
impl Bus68k { pub fn read16(&mut self, addr:u32)->u16; pub fn write16(&mut self, addr:u32, data:u16, upper:bool, lower:bool); }
```
`read16(addr)` : `a = addr & 0xFFFFFE` (accès toujours aligné) puis `match a >> 16` :
- `0x00`: si `a < 0x80` : `vectors_from_cart ? cart_p : bios` (mot big-endian à `a`) ; sinon `cart_p[a..a+2]` si `a+1 < min(cart_p.len(), 0x100000)` sinon `open_bus`.
- `0x01`: RAM : `work_ram[a & 0xFFFF ..]` (mot BE). (miroir $110000-$1FFFFF : `a>>16` vaut 0x10..0x1F : tester `(a>>20)==1`.)
- `(a>>20)==2`: si `port` est Some ET `port.read(a, &cart_p, &work_ram[..]) == Some(v)` => `v` ; sinon `cart_p[pbank_base + (a & 0xFFFFF) ..]` (mot BE) si dans la taille, sinon `open_bus`.
- `(a>>20)==3`: `match (a>>16)&0xFE` : `0x3C` => `lspc.read(a)` ; `0x30|0x32|0x34|0x38|0x3A` => `io.read(a)` ; sinon `open_bus`.
- `(a>>20)` in 4..=7 : `palette.read(a)`.
- `(a>>20)` in 8..=0xB : `memcard.read(a)`.
- `(a>>20)==0xC`: `bios[a & 0x1FFFF ..]`.
- `(a>>20)==0xD`: `backup.read(a)`.
- autre : `open_bus`.
`write16` : mêmes zones ; ROM/BIOS ignorées ; RAM : si `upper` écrire l'octet haut (`work_ram[i]`), si `lower` l'octet bas (`work_ram[i+1]`) ; périphériques : appeler `.write(a, data, upper, lower)` ; zone 0x200000 -> si `port` est Some et `port.write(a, data, upper, lower, &cart_p, &work_ram[..])` retourne true : fini (voir CartPort) ; sinon T306 ajoute la bank-select ; le reste ignoré.
Dans device.rs aussi : `pub trait CartPort { fn read(&mut self, a:u32, p:&[u8], wram:&[u8]) -> Option<u16>; fn write(&mut self, a:u32, d:u16, upper:bool, lower:bool, p:&[u8], wram:&[u8]) -> bool; /* true = écriture consommée */ fn take_bank(&mut self)->Option<u32> { None } /* nouveau décalage P ROM demandé par la dernière écriture */ fn reset(&mut self) {} }` ; après un `write` consommé : `if let Some(b)=port.take_bank() { pbank_base=b }`.
Fournir `NullDevice` (lecture 0xFFFF, écriture ignorée) pour construire un Bus en test. Constructeur : `Bus68k::new(bios:Vec<u8>, cart_p:Vec<u8>)` avec tous les devices = NullDevice.

## Tests à écrire (valeurs exactes)
- RAM : write16(0x100000,0x1234,true,true) puis read16(0x100000)==0x1234 ; read16(0x110000)==0x1234 (miroir) ; read16(0x1F0000)==0x1234.
- Écriture octet haut seul : write16(0x100002,0xAB00,true,false) laisse l'octet bas inchangé.
- BIOS : bios[0..4]=[0x00,0x10,0x00,0x00] -> read16(0xC00000)==0x0010, read16(0xC20000)==0x0010 (miroir), read16(0xC00002)==0x0000.
- Vecteurs : cart_p[0..2]=[0xAA,0xBB], bios[0..2]=[0x11,0x22] : read16(0)==0x1122 puis après `vectors_from_cart=true` -> 0xAABB ; read16(0x80) lit toujours cart_p.
- Fenêtre : cart_p de 0x300000 octets, pbank_base=0x100000 : read16(0x200000)==mot de cart_p[0x100000..].
- Non mappé : open_bus=0xBEEF -> read16(0xE00000)==0xBEEF.
- Écriture ROM (write16(0xC00000,..)) ne change rien.
