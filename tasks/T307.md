## Spécification (décidée, ne pas réinterpréter)
Mode `Model::Aes` (champ `io.model`) — différences par rapport au MVS, toutes issues de MAME :
- Pas de backup RAM : `$D00000-$FFFFFF` => open bus (la carte lit `open_bus`).
- Lecture `$300000` : `(pad1.bits << 8) | 0xFF` ; `$340000` idem pad2 ; pas de DIP : `$300081/$300080` => `0xFF00` (MAME AES n'a pas de port TEST : renvoyer `open_bus`).
- Lecture `$380000` : `0x00FF | ((system.bits & 0x03) << 8) | (((system.bits >> 2) & 0x03) << 10) as u16 | 0x7000` (bit 15 = 0 : AES) ; start/select de P1 en bits 8-9, de P2 en bits 10-11.
- Lecture `$320000` : `(sound_reply << 8)` (bits 0-4 : 0 car IPT_UNKNOWN, bits 5-7 : 0 car pas de RTC ni slot).
- Écriture du latch système et des registres de sortie identique au MVS ; le watchdog est absent (ignorer l'écriture `$300001` et ne pas arrêter la machine).
- Horloge maître : `MCLK_HZ_AES` (n'influence que la conversion en secondes réelles ; les ticks restent en mclk).
