## Spécification (décidée, ne pas réinterpréter)
Reset (MAME) : le Z80 est tenu en reset tant que le 68000 n'a pas écrit le registre `REG_SOUND`... **DÉCISION simple** : Z80 exécute dès le reset (le BIOS sm1 ne fait rien tant qu'aucune commande n'arrive) ; `sound.reset()` après `z80.power()`.
API publique stable pour la GUI/tests : `pub fn load_machine(cfg:&Config, game:&str)->Result<Machine,String>` (cherche le zip dans `cfg.roms_dir`, `find_def`, `load_cart`, `load_bios(cfg.bios_dir,&cfg.bios)`, applique la protection (P7) via `cart.install(&mut bus)` : stub ne faisant rien ici), `Machine::set_inputs(&mut self, p1:PadState, p2:PadState, sys:SystemButtons)`, `Machine::run_frame()`, `Machine::framebuffer()->&Framebuffer`, `Machine::take_audio()->Vec<[f32;2]>`, `Machine::frame_count()`.
Sauvegarde backup : `Machine::save_backup(&self)`, `load_backup(&mut self)` chemin `saves_dir/<game>.sram`.
