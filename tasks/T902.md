## Spécification (décidée, ne pas réinterpréter)
Procédure (le LLM local ne cherche rien sur le web) : l'utilisateur dépose ses ROMs de test (exemples ngdevkit compilés, ou toute ROM de test qu'il a trouvée ; le wiki neogeodev n'en fournit pas) dans `tests-data/hwtests/<nom>/` ; `docs/spec/data/test-roms.md` liste pour chacune : nom, taille, nombre de trames à exécuter, but (LSPC timing, palette, sprites, fix, audio). Pour chaque ROM : `tools/mame_golden.ps1 -Game <nom> -Frames ...` génère les captures dans `tests-data/hwtests/<nom>/golden/`. `hwtests.rs` charge chaque dossier, exécute N trames et compare ; chaque test est `#[ignore]` tant que ses fichiers manquent. **Vérité terrain : MAME (pas le matériel)** ; les écarts MAME/matériel connus sont à lister dans le .md.
