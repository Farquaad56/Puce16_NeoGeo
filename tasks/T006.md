## Spécification (décidée, ne pas réinterpréter)
Dépendance autorisée par cette carte : `cargo add -p ng-testkit png` (décodage PNG). 
```rust
pub struct Diff { pub different: usize, pub total: usize, pub first: Option<(usize,usize)> /* (x,y) du premier écart */ }
pub fn load_png_rgb(path:&std::path::Path) -> Result<(usize,usize,Vec<u32>),String>;   // 0x00RRGGBB, ligne par ligne
pub fn diff_frame(fb:&ng_common::Framebuffer, golden:&[u32], w:usize, h:usize) -> Result<Diff,String>; // Err si (w,h) != (320,224)
pub fn write_diff_ppm(fb:&ng_common::Framebuffer, golden:&[u32], path:&std::path::Path) -> std::io::Result<()>; // pixels identiques en gris, différents en rouge
```
Les snapshots de MAME (`screen:snapshot()`) font 320×224 pour le Neo Geo ; toute autre taille est une erreur explicite (« taille golden WxH, attendu 320x224 »). Les PNG RGBA sont acceptés (alpha ignoré).

## Tests à écrire (valeurs exactes)
- Un PNG 2×2 écrit par le test (via le crate png) se relit à l'identique.
- diff_frame d'une trame et de sa propre copie : different == 0 et total == 71680.
- Un pixel modifié : different == 1 et first == Some((x,y)) exact.
- Golden 100×100 => Err contenant `320x224`.
