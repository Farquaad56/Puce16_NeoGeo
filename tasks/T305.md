## Spécification (décidée, ne pas réinterpréter)
```rust
pub trait Ym { fn advance(&mut self, mclk:u64); fn read(&mut self, port:u8)->u8; fn write(&mut self, port:u8, v:u8); fn irq(&self)->bool; }   // port 0..3 = adresses A/B Z80 $04..$07
pub struct SoundBoard<Y:Ym> {
    pub time: u64,                // temps Z80 en mclk : += 6 à chaque tick
    pub sm1: Vec<u8>, pub m1: Vec<u8>, pub ram: [u8;0x800],
    pub use_cart: bool,           // latch q5 (CRTFIX) : fenêtre $0000-$7FFF = m1 (cart) ou sm1 (BIOS)
    pub bank: [u8;4],             // numéros de banque des fenêtres $F000, $E000, $C000, $8000 (index 0..3)
    pub cmd: u8, pub cmd_pending: bool,
    pub reply: u8,
    pub nmi_enabled: bool,
    pub ym: Y,
    port: Z80Port,                // z80port.rs : état du serveur de broches
}
impl<Y:Ym> SoundBoard<Y> {
    pub fn read(&mut self, addr:u16)->u8;  pub fn write(&mut self, addr:u16, v:u8);
    pub fn input(&mut self, addr:u16)->u8; pub fn output(&mut self, addr:u16, v:u8);
    pub fn tick(&mut self, cpu:&mut puce_z80::Cpu);   // UN T-state (6 mclk)
}
```
**Mémoire et ports** (inchangés, fonctions inhérentes appelées par `tick`) :
- `read(addr)` : `$0000-$7FFF` : `(if use_cart {&m1} else {&sm1})[addr]` (0xFF si hors taille) ; `$F800-$FFFF` RAM ; fenêtres : index i (0=$F000 2Kio,1=$E000 4Kio,2=$C000 8Kio,3=$8000 16Kio) ; `base = [0xF000,0xE000,0xC000,0x8000][i]` ; `off = 0x10000 + (((bank[i] as usize) << (11+i)) & mask) + (addr - base)` avec `mask = (m1.len() - 0x10000 - 1) & 0x3FFFF` (voir 03) ; lecture de `m1[off]` (0xFF si hors taille). Fenêtre sélectionnée par `addr` : $8000-$BFFF -> i=3 ; $C000-$DFFF -> i=2 ; $E000-$EFFF -> i=1 ; $F000-$F7FF -> i=0.
- `write(addr,v)` : seulement la RAM $F800-$FFFF.
- `input(addr)` : `port = addr as u8` ; `match port & 0x0F` : `0x00` : `cmd_pending=false` ; renvoie `cmd` ; `0x04..=0x07` : `ym.advance(self.time); ym.read(port&3)` ; `0x08..=0x0B` : `bank[(port & 3)] = (addr >> 8) as u8` ; renvoie 0 ; autres : 0xFF.
- `output(addr,v)` : `port=addr as u8` : `0x00` (écriture) : `cmd_pending=false` ; `0x04..=0x07` (après `& 0x0F`, bits 4-7 ignorés) : `ym.advance(self.time); ym.write(port&3, v)` ; `(port & 0x0F)==0x08` : `nmi_enabled = (port & 0x10) == 0` ; `0x0C` : `reply = v` ; autres ignorés.
- `reset()` : `bank = [0x1E, 0x0E, 0x06, 0x02]`, `cmd_pending=false`, `nmi_enabled=false`, `port = Z80Port::default()`, `time` inchangé.
- `pub fn host_write_cmd(&mut self, v:u8)` (appelé par le 68000) : `cmd=v; cmd_pending=true`. `pub fn nmi_level(&self)->bool { cmd_pending && nmi_enabled }` ; `pub fn irq_level(&self)->bool { ym.irq() }`.
**Serveur de broches** (`tick`) : reproduire EXACTEMENT, pour un seul T-state, le corps de la boucle de `puce_z80::Cpu::step` (ref/cpu-crates/z80/src/cpu.rs l.484-560) avec ces différences : (a) l'état `last: Pins`, `read_data: Option<u8>`, `write_done: bool` est stocké dans `Z80Port` (z80port.rs, `#[derive(Default)]`) ; (b) lecture mémoire/port/acquittement : données `self.read(addr)` / `self.input(addr)` / 0xFF ; écritures : `self.write` / `self.output` ; (c) `INT` placé dans les broches d'entrée si `irq_level()`, `NMI` si `nmi_level()` (le CPU mémorise le front lui-même) ; (d) jamais de `WAIT` ni de `BUSRQ` ; (e) après `cpu.tick(pins_in)` : `self.port.last = sortie` et `self.time += 6`. Les accès YM utilisent `self.time` valeur AVANT l'incrément (début du T-state).

## Tests à écrire (valeurs exactes)
- m1 de 0x30000 octets : bank[0]=0x1E (fenêtre $F000, i=0), mask=(0x30000-0x10000-1)&0x3FFFF=0x1FFFF : off = 0x10000 + ((0x1E<<11)&0x1FFFF) = 0x1F000 ; read(0xF000)==m1[0x1F000].
- input(0x0508) => bank[0]=5 ; la lecture suivante en $F000 vient de m1[0x10000 + ((5<<11)&mask)].
- host_write_cmd(0xAB) puis input(0x0000) renvoie 0xAB et cmd_pending=false. output(0x000C,0x42) => reply==0x42.
- output(0x0008,..) active la NMI (nmi_enabled) ; output(0x0018,..) la désactive ; nmi_level() == cmd_pending && nmi_enabled.
- RAM : write(0xF800,0x11) puis read(0xF800)==0x11 ; write(0x8000,..) ne change rien ; $0000 lit m1 si use_cart sinon sm1.
- Vrai CPU, programme `3E 12 D3 0C 76` (LD A,$12 ; OUT ($0C),A ; HALT) dans sm1 : après au plus 30 appels de tick, `reply==0x12` ; `time == 6 * nombre_de_ticks`.
- Vrai CPU, `host_write_cmd(0xAB)` puis programme `DB 00 76` (IN A,($00) ; HALT) : après au plus 30 ticks, `cpu.regs.a==0xAB` et `cmd_pending==false`.
- Vrai CPU, NMI : `host_write_cmd(1)` puis sm1 = `D3 08` à l'adresse 0 et `3E 77 76` à l'adresse 0x66 (LD A,$77 ; HALT) : après au plus 60 ticks, `cpu.regs.a==0x77`.
