## Spécification (décidée, ne pas réinterpréter)
Dépendances : `cargo add -p ng-core serde --features derive` et `bincode` (version 1.3). Ajouter `#[derive(Serialize,Deserialize)]` aux états des cœurs (champs publics : registres, RAM, VRAM, palette, YM, timers, `now`...) — dans chaque crate concerné, derrière une feature `serde` activée par ng-core. `Machine::save_state()->Vec<u8>` ; `load_state(&[u8])->Result<(),String>` ; format : magic `NGST`, version u32=1, puis bincode. Les ROM (cart, bios) NE sont PAS sauvegardées : un hash CRC32 de P est stocké et vérifié au chargement. **CPU (v5)** : les deux CPU ne se sauvent qu'à une frontière d'instruction : `Machine::save_state` appelle d'abord `finish_instruction()`. 68000 : `puce_m68k::state::CpuState` n'a pas de serde, sérialiser à la main (little-endian) d[8], a[7], usp, ssp, sr, pc, prefetch[2] ; Z80 : `puce_z80::Cpu::save_state()->Option<CpuState>` (feature `serde` de puce-z80, à activer dans `[workspace.dependencies]`) ; sauver aussi `Z80Port` (T305). Limite connue : l'état STOP/arrêt du 68000 n'est pas dans `CpuState` (voir QUESTIONS Q-M68KSTATE).
