## Spécification (décidée, ne pas réinterpréter)
Onze jeux sont dans `roms/` mais PAS dans `ref/mame-neogeo/neogeo.cpp` (autres pilotes MAME) : cnbe columnsn ffeast ltorb neonopon neopong neothund ngem2k ngtetris poknight totc. Ils ont le même format de cartouche (fichiers `<n>.p1 .s1 .m1 .v1 .c1 .c2`). `powerins.zip` n'est PAS un jeu Neo Geo (carte arcade d'un autre constructeur) : l'ignorer et le noter dans `docs/CATALOGUE.md`. `aes.zip`, `neogeo.zip`, `neocdz.zip` sont des BIOS, pas des jeux.
1. `tools/extract_listxml.py` appelle `X:\Mame_0287\mame.exe -listxml <jeu>` pour chacun des 11 jeux (une seule exécution `-listxml cnbe columnsn ...`), garde pour chaque `<machine>` : nom, description, parent (`romof`/`cloneof`), et les éléments `<rom name size crc sha1 region offset>` ; écrit `docs/spec/data/romsets_extra.xml`.
2. `gen_tables.py` lit ce XML (`xml.etree`) pour ces jeux. Conversion des régions `<rom region=...>` : `maincpu`->P (WordSwap si `loadflag="load16_word_swap"`), `fixed`->S, `audiocpu`->M (avec le même `m1_reload` 128K/64K que `NEO_BIOS_AUDIO_*` : M = taille+0x10000, rechargement à 0x10000), `ymsnd:adpcma`->V, `ymsnd:adpcmb`->VB, `sprites`->C (octet pair/impair selon `loadflag="load16_byte"` et `offset`). Les fichiers présents dans le zip mais absents de la machine (sous-dossiers de clones, ex. `poknightcd/...`) sont ignorés. Les `<rom>` d'un parent (`romof`) sont inclus s'ils sont dans le zip.
3. Aucune protection (`PROT_NONE`) sauf si `-listxml` indique un périphérique de protection (le noter et traiter au cas par cas : `blocked` + `docs/QUESTIONS.md`).
4. Ajouter les 11 jeux au `CATALOGUE` ; mettre à jour `ALL_CARTS` et le test de comptage.
