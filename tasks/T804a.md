## Spécification (décidée, ne pas réinterpréter)
Infrastructure commune de sauvegarde des réglages de l'interface. Fichier `gui.toml` placé dans le même dossier que `neogeo.toml` (`cfg_path.parent()`), distinct de `neogeo.toml` (qui garde chemins, modèle et BIOS via `config_to_toml`). `prefs.rs` : `#[derive(Clone, Debug, PartialEq)] pub struct Prefs { pub display: DisplayPrefs, pub input: InputPrefs, pub debug: DebugPrefs }` avec `Default`. `DisplayPrefs { scale: ScaleMode /*Auto|Fixed(u32)*/, fullscreen: bool, aspect: Aspect /*Square|Tv4x3*/, smooth: bool /*false*/ }`, `InputPrefs { keys: Vec<(String,String)> /*action -> nom de touche egui, vide = défauts*/, pad: Vec<(String,String)> }`, `DebugPrefs { open: bool, tab: String, show_status_bar: bool }`. `Prefs::to_toml()->String`, `Prefs::from_toml(&str)->Prefs` (parseur ligne à ligne `[section]` / `clé = valeur`, comme `parse_config` ; clés inconnues ou invalides ignorées, valeur par défaut), `Prefs::load(path)->Prefs` (fichier absent ou illisible = défauts), `Prefs::save(&self, path)->Result<(),String>` (écriture dans `gui.toml.tmp` puis `rename`, jamais de fichier tronqué). `App` charge les prefs au démarrage et les sauvegarde quand elles changent (comparer à la dernière valeur sauvée, pas d'écriture à chaque trame) et à la fermeture. Pas de nouvelle dépendance.

- Clé inconnue ignorée, clé connue conservée ; `scale = "fixed:3"` -> `Fixed(3)`, `scale = "auto"` -> `Auto`.
- `save` ne laisse pas de `.tmp` et le fichier relu est identique.
