## Spécification (décidée, ne pas réinterpréter)
```rust
pub struct Palette { pub ram: Box<[u16; 0x2000]>, pub pens: Box<[u32; 0x4000]> /* 0..0x1FFF normal, 0x2000..0x3FFF shadow */, pub bank: u8 /*0|1*/, pub shadow: bool }
impl Palette { pub fn new()->Self; pub fn read16(&self, off:usize)->u16; pub fn write16(&mut self, off:usize, data:u16); pub fn pens_base(&self)->&[u32]; pub fn backdrop(&self)->u32; }
```
`off` = index de mot dans la banque courante (0..0xFFF). Zone bus : `$400000-$401FFF` miroir tous les 0x2000 jusqu'à `$7FFFFF` : `off = (addr >> 1) & 0xFFF` (Device wrapper dans ng-core).
- `read16(off)` : `ram[bank*0x1000 + off]`.
- `write16(off, data)` : `i = bank*0x1000 + off` ; `ram[i]=data` ; `dark = data>>15` ; `r = ((data>>14)&1) | ((data>>7)&0x1E)` ; `g = ((data>>13)&1) | ((data>>3)&0x1E)` ; `b = ((data>>12)&1) | ((data<<1)&0x1E)` ; `pens[i] = rgb(DAC[r][dark], DAC[g][dark], DAC[b][dark])` ; `pens[i+0x2000] = rgb(DAC[r][dark+2], ...)` avec `rgb(r,g,b)=(r<<16)|(g<<8)|b` (0x00RRGGBB). Les écritures octet seul (upper/lower) fusionnent avec `ram[i]` avant l'appel.
- `pens_base()` = `&pens[bank*0x1000 + (shadow ? 0x2000 : 0) ..]` (tranche de 0x1000 entrées).
- `backdrop()` = `pens_base()[0xFFF]`.
- Au reset toute la RAM = 0 et `pens` = noir (0) ; MAME ne recalcule PAS les pens à la mise à zéro : pen 0 = noir.

## Tests à écrire (valeurs exactes)
- write16(0, 0x0000) => pens[0]==0 ; write16(0, 0x7FFF) : r=((0x7FFF>>14)&1)|((0x7FFF>>7)&0x1E)=1|0x1E=31, g=31, b=((0x7FFF>>12)&1)|((0x7FFF<<1)&0x1E)=1|0x1E=31 => pens[0]==rgb(DAC[31][0]x3) (lire la table dans le test).
- write16(1, 0x8000) : dark=1, r=g=b=0 => pens[1]==rgb(DAC[0][1]..)=0 ; write16(2,0x8FFF)? : dark=1 : r=(0x8FFF>>7)&0x1E=0x1E|((0x8FFF>>14)&1=0)=30 => canal rouge DAC[30][1].
- Ombre : pens[0x2000+i] utilise la colonne dark+2.
- Bank=1 : write16(5,x) écrit ram[0x1005] et read16(5) la relit ; bank=0 ne la voit pas.
- backdrop : write16(0xFFF, 0x7FFF) bank 0 => backdrop()==pens[0xFFF] ; shadow=true => pens[0x2FFF].
