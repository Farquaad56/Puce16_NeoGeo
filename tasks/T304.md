## Spécification (décidée, ne pas réinterpréter)
- **Backup RAM** `$D00000-$DFFFFF` (miroir 64 Kio) : `struct BackupRam { pub data: Box<[u8;0x10000]>, pub unlocked: bool }` implémente `Device` : lecture mot BE à `a & 0xFFFF` ; écriture mot (selon upper/lower) UNIQUEMENT si `unlocked` (recopié depuis le latch q6 par le Machine). Persistance : `pub fn load(&mut self, path:&Path)` / `save(&self, path:&Path)` (fichier brut de 65536 octets ; si le fichier n'existe pas : mettre tout à 0x00).
- **Mémoire carte** `$800000-$BFFFFF` : `struct MemCardStub` : lecture => `0xFFFF`, écriture ignorée (carte absente). La vraie carte est la carte T902.
- **RTC** `rtc.rs` : PORTER `upd1990a.cpp` (BSD-3, mêmes états : registre à décalage 52/64 bits, commandes register hold / shift / time set / time read / TP 64 Hz-256 Hz-2048 Hz-1 s...). API : `struct Upd4990a`, `fn set_inputs(&mut self, stb:bool, clk:bool, din:bool)` (appelé quand le registre $380051 est écrit), `fn data_out(&self)->bool`, `fn tp(&self)->bool`, `fn time_counter(&self)->[u8;6]`, `fn advance(&mut self, mclk:u64)` (le TP est dérivé de l'horloge 32,768 kHz : 1 tick RTC = 24e6/32768 mclk ≈ 732,42 mclk ; garder un accumulateur fractionnaire), `fn set_time(&mut self, y:u16, mo:u8, d:u8, wd:u8, h:u8, mi:u8, s:u8)` (valeurs source = horloge système, fournies par le Machine ; en test : valeurs fixes).

## Règles de portage C++ -> Rust (cartes « port »)
- Traduire fonction par fonction, DANS L'ORDRE du fichier source, mêmes noms en snake_case (`instructionADD` -> `instruction_add`). Chaque appel `wait/idle/read/write/prefetch/step` du C++ reste un appel DANS LE MÊME ORDRE : c'est ce qui produit les cycles exacts. Ne pas « optimiser », ne pas fusionner, ne pas réordonner.
- Types : n1 -> bool, n4/n8 -> u8, n16 -> u16, n24/n32 -> u32, n64 -> u64, i8/i16/i32 signés. Les entiers sans signe de ares/ymfm sont modulo 2^N : utiliser `wrapping_add/sub/mul/shl` ou des masques explicites ; jamais d'arithmétique qui panique en debug.
- `template<u32 Size>` -> paramètre const générique `const SIZE: u32` (0=Byte, 1=Word, 2=Long) ; `uint` de ymfm -> u32.
- Conserver l'en-tête de licence (ares : ISC, voir ref/ares/LICENSE ; ymfm / MAME : BSD-3, voir ref/ymfm/LICENSE et l'en-tête `// license:BSD-3-Clause` des fichiers) en commentaire en tête de chaque fichier Rust porté, avec le nom du fichier source.
- Si le C++ utilise une construction sans équivalent évident : écrire la plus simple équivalente et noter `// PORT-NOTE:` ; ne pas changer le comportement.
