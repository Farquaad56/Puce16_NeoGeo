## Spécification (décidée, ne pas réinterpréter)
```rust
pub struct Bios { pub main: Vec<u8> /*0x20000, octets big-endian du 68000*/, pub lo: Vec<u8> /*000-lo.lo = 0x20000 octets (zoom Y) */, pub sfix: Vec<u8> /*sfix.sfix 0x20000*/, pub sm1: Vec<u8> /*sm1.sm1 0x20000*/ }
pub fn load_bios(dir:&Path, main_file:&str)->Result<Bios,BiosError>;
pub enum Model { Mvs, Aes }
pub struct Config { pub bios_dir:PathBuf, pub roms_dir:PathBuf, pub saves_dir:PathBuf, pub model:Model, pub bios:String }
pub fn parse_config(text:&str)->Result<Config,String>;      pub fn load_config(path:&Path)->Result<Config,String>;
```
Dépendance : `cargo add -p ng-cart toml --no-default-features --features parse` ; lecture : `text.parse::<toml::Table>()` puis `table["paths"]["bios_dir"].as_str()` (pour chacune des 5 clés ; pas de serde). Clés obligatoires : paths.bios_dir, paths.roms_dir, paths.saves_dir, system.model ("mvs"|"aes", insensible à la casse), system.bios.
`load_bios` : utilise `Source::open(dir/"neogeo.zip")` s'il existe, sinon `Source::Dir(dir)`. `main` = fichier `main_file` chargé en **WordSwap** (comme `ROM_LOAD16_WORD_SWAP_BIOS` : échange des 2 octets de chaque mot) ; taille exigée 0x20000, sinon `BiosError::UnsupportedSize(n)` (les BIOS 512 Kio sp-45/sp-j3 ne sont pas gérés : noter dans docs/QUESTIONS.md). `lo`, `sfix`, `sm1` : chargés tels quels depuis `000-lo.lo`, `sfix.sfix`, `sm1.sm1` (tailles 0x20000 chacun ; erreur sinon). Pas de vérification de CRC pour le BIOS.
