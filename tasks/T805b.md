## Spécification (décidée, ne pas réinterpréter)
Remplacer les fenêtres flottantes séparées par **une seule fenêtre « Débogueur » à onglets** : `CPU | Mémoire | Vidéo | Palette | Sprites` (les trois derniers sont remplis par T805c ; ici l'onglet Vidéo/Palette/Sprites affiche « voir T805c »). Menu Débogage (remplace le bouton) : Afficher (F12), Pause (F5), **Avancer d'une trame** (F6, pause + `Cmd::StepFrame`), Onglet… . Barre d'état en bas de la fenêtre principale (`statusbar.rs`, `pub fn format_status(&StatusInfo)->String` pure) : `jeu · BIOS · MVS|AES · trame N · 59.2 fps · x3 (960x672) · PAUSE|MARCHE` (le BIOS vient de T804b, l'échelle de T805a ; valeurs absentes = « – »). **Onglet CPU** : colonnes ordonnées — 68000 : PC, SR décodé en drapeaux (`T S INT=n X N Z V C` avec les bits actifs en gras), D0-D7 sur deux colonnes de 4, A0-A7 (A7 = pile active) ; Z80 : AF BC DE HL IX IY SP PC + drapeaux ; horodatage `now` (mclk) et `vpos`/ligne ; les registres **modifiés depuis la trame précédente** sont surlignés. **Onglet Mémoire** : sélecteur de région (RAM travail $100000, RAM Z80 $F800, RAM palette, VRAM), champ « Aller à » (hexadécimal, Entrée), 16 octets/ligne avec colonne ASCII, octets modifiés surlignés, `show_rows`. **Coût** : `Cmd::Debug(DebugLevel)` remplace `Cmd::Debug(bool)` avec `DebugLevel { Off, Cpu, Memory, Video }` ; le cœur ne copie que ce que l'onglet visible demande (CPU = registres seuls ; Mémoire = la région choisie ; Vidéo = VRAM+palette+fix) ; instantané envoyé une trame sur deux quand le débogueur est ouvert (une par trame en pause). Persistance : fenêtre ouverte/onglet actif/région dans `Prefs.debug`.
