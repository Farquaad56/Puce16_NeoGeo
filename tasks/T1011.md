## Spécification (décidée, ne pas réinterpréter)
kof98 : pas de CMC ; code 68000 chiffré « précoce » et **recouvrement de ROM** (overlay) géré par une puce Altera, vérifié à plusieurs endroits du jeu.
- `PDecrypt::Kof98` : portage exact de `kof98_prot_device::decrypt_68k` (`prot_kof98.cpp`) : copie de 0x200000 octets, permutations par blocs de 0x200, puis `memmove(&p[0x100000], &p[0x200000], 0x400000)`. Après déchiffrement, mémoriser `default_rom = [mot P[0x100], mot P[0x102]]` (utilisé par le port).
- `RuntimeProt::Kof98` : port `CartPort` (`prot_kof98.rs`) = portage exact de `protection_r`/`protection_w` de `prot_kof98.cpp` (état `prot_state`, valeurs de retour 0x00C2, 0x0000, etc., sinon `default_rom`). Adresses : celles du câblage MAME (`kof98.cpp` : `protection_r(offset)` / `protection_w(data)` sur la fenêtre cartouche $200000-$2FFFFF ; l'adresse d'écriture exacte est testée dans `protection_w` — lire le fichier).
- Pas de CMC, pas de PCM2, `fix_bank == Std`. `Protection` : `p_decrypt: Kof98, runtime: Kof98`.
