## Spécification (décidée, ne pas réinterpréter)
Menu « Système » : (1) sous-menu **BIOS** listant les BIOS connus avec une pastille présent/absent ; (2) choix du **modèle** MVS / AES. `bios_menu.rs` : `pub const KNOWN_BIOS: &[(&str /*fichier*/, &str /*libellé*/)]` repris de la macro NEOGEO_BIOS du fichier de référence (sp-s2.sp1 « Europe MVS (Ver. 2) », sp-s.sp1, sp-s3.sp1, sp-u2.sp1, sp-e.sp1, sp1-u2, sp1-u4.bin, et les BIOS AES `neo-epo.bin`, `neo-po.bin`, `uni-bios*` s'ils figurent dans le fichier ; **exclure** les BIOS de 512 Kio (QUESTIONS Q-BIOS512)) ; `pub fn available_bios(cfg:&Config)->Vec<(&'static str,&'static str,bool)>` : présent = `ng_cart::load_bios(&cfg.bios_dir, fichier).is_ok()`. Choisir un BIOS ou un modèle : met à jour `cfg` en mémoire, réécrit `neogeo.toml` avec `config_to_toml` (écriture atomique `.tmp` + rename), puis **redémarre le jeu courant** (`Cmd::Load` du même jeu avec la nouvelle config : `EmuHandle::spawn` n'est pas relancé, ajouter `Cmd::Config(Config)` au thread d'émulation qui remplace sa copie de config avant le `Load`). BIOS absent : entrée grisée avec info-bulle « fichier introuvable dans <bios_dir> ». Le BIOS et le modèle actifs sont cochés ; le nom du BIOS s'affiche dans la barre d'état (T805b). Si le BIOS configuré n'existe pas au démarrage : message d'erreur dans l'interface et ouverture du menu BIOS (pas de panique).
