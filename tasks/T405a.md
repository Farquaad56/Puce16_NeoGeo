## Spécification (décidée, ne pas réinterpréter)
```rust
pub fn sprite_gfx_mask(len:usize)->u32;                       // get_region_mask (l.542-562)
pub fn draw_sprites_line(vram:&[u16], c_rom:&[u8], zoomy:&[u8] /*000-lo.lo*/, pens:&[u32], anim_counter:u8, anim_disabled:bool, vpos:u16, out:&mut [u32;320]);
```
`sprite_gfx_mask(len)` : `mask=0xFFFF_FFFF; for bit in (0..32).rev().map(|b|1u32<<b) { if ((len as u32)*2 - 1) & bit != 0 { break } ; mask >>= 1 }`. `draw_pixel(c, romaddr:u32, dst:&mut u32, line_pens:&[u32])` : `s = ((romaddr & !0xFF) >> 1) | (((romaddr & 8) ^ 8) << 3) | ((romaddr & 0xF0) >> 2)` ; `x = romaddr & 7` ; `gfx = (bit(c[s+3],x)<<3) | (bit(c[s+1],x)<<2) | (bit(c[s+2],x)<<1) | bit(c[s+0],x)` ; `if gfx != 0 { *dst = line_pens[gfx] }`.
`draw_sprites_line` = port 1:1 de `draw_sprites` (l.283-461), `scanline = vpos` : liste active = `vram[0x8680..]` si `vpos` impair sinon `vram[0x8600..]` ; `max_sprite_index` (dernier non nul, +1 si ≠ 95) ; pour chaque `sprite_index` 0..=max : `sprite_number = list[i] & 0x1FF` ; `y_control = vram[0x8200|n]`, `zoom_control = vram[0x8000|n]` ; chaîné (bit 6) : `x = (x + zoom_x + 1) & 0x1FF ; zoom_x = (zoom_control>>8)&0xF` sinon `y = 0x200 - (yc>>7) ; x = vram[0x8400|n] >> 7 ; zoom_y = zoom_control & 0xFF ; zoom_x = (zoom_control>>8)&0xF ; rows = yc & 0x3F` ; si `0x140 <= x <= 0x1F0` continue ; si `sprite_on_scanline(...)` : `sprite_line = (vpos - y) & 0x1FF ; zoom_line = sprite_line & 0xFF ; invert = bit8 de sprite_line ; if invert { zoom_line ^= 0xFF }` ; `if rows > 0x20 { zoom_line %= (zoom_y+1)<<1 ; if zoom_line > zoom_y { zoom_line = ((zoom_y+1)<<1) - 1 - zoom_line ; invert = !invert } }` ; `t = zoomy[(zoom_y<<8)|zoom_line]` ; `sprite_y = t & 0xF ; tile = t >> 4` ; `if invert { sprite_y ^= 0xF ; tile ^= 0x1F }` ; `ao = (n<<6) | (tile<<1)` ; `attr = vram[ao+1]` ; `code = ((attr << 12) & 0xF0000) | vram[ao]` ; animation (si non désactivée) : bit 3 de attr : `code = (code & !7) | (anim & 7)` sinon bit 2 : `(code & !3) | (anim & 3)` ; `if attr & 2 { sprite_y ^= 0xF }` ; `zt = ZOOM_X[zoom_x]` ; `gfx_base = ((code<<8)|(sprite_y<<4)) & mask` ; `line_pens = &pens[(attr>>8)<<4 ..]` ; flip X (bit 0) : `gfx_base += 0xF ; x_inc=-1` sinon +1 ; si `x <= 0x1F0` : pixel = `out[x]` (ATTENTION : `out[0]` correspond à l'écran x=0 ; x ∈ 0..=0x13F ; écrire seulement si `x+i < 320` — MAME écrit dans la marge, ici on tronque) : pour i in 0..16 : `if zt & 0x8000 != 0 { draw_pixel(gfx_base, out[x_cur]); x_cur+=1 }` ; `zt <<= 1` (u16) ; `if zt == 0 break` ; `gfx_base += x_inc` ; sinon (x > 0x1F0, enroulement) : même boucle mais en incrémentant `x` local et en dessinant seulement quand `x >= 0x200` à la colonne `x - 0x200`, restaurer `x`.

## Tests à écrire (valeurs exactes)
- sprite_gfx_mask(0x400000)==0x7FFFFF ; (0x800000)==0xFFFFFF ; (0x20000)==0x3FFFF.
- draw_pixel romaddr=0 : s = 0 | (((0&8)^8)<<3 = 0x40) | 0 = 0x40 : avec c[0x40]=0x01 (reste 0) => gfx==1 (plan 0, bit 0).
- draw_pixel romaddr=0x8 : s = ((8&8)^8)<<3 = 0 : avec c[3]=0x01 (reste 0), x=0 => gfx==8 (plan 3).
- Zoom X plein (zoom_x=15 => ZOOM_X[15]=0xFFFF) : 16 pixels consécutifs écrits ; zoom_x=0 (0x0080) : 1 pixel.
- Flip X : les adresses décroissent ; flip Y (attr bit 1) : sprite_y ^= 0xF.
- Animation : attr bit 3 et anim=5 : code & !7 | 5.
- Sprite x=0x1F8 (>0x1F0) : colonne 0 écrite seulement pour pixels avec x>=0x200.
