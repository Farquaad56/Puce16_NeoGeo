## Spécification (décidée, ne pas réinterpréter)
Dépendance : `cargo add -p ng-gui cpal`. `pub struct AudioOut { stream: cpal::Stream, shared: Arc<Mutex<VecDeque<f32>>> /*stéréo entrelacé*/ , rate:u32 }` ; `AudioOut::new()->Result<AudioOut,String>` : périphérique par défaut, config f32 stéréo (si le format n'est pas f32 : erreur claire) ; le callback remplit depuis le deque, complète par du silence (0.0) en cas de sous-alimentation. `push(&self, samples:&[f32])` ; le deque est plafonné à 0,25 s (`rate/2` valeurs) : au-delà on jette les plus anciens. Le thread d'émulation utilise `AudioResampler::new(55555.56 /*MVS*/, rate)`, convertit `machine.take_audio()` et appelle `push`. Synchro : l'émulation reste cadencée par `Instant` (T800a) ; l'audio n'est PAS la horloge maître (noté QUESTIONS).
