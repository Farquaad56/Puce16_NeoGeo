## Spécification (décidée, ne pas réinterpréter)
Trois jeux avec la puce SMA : code 68000 chiffré + banques commandées par la puce + (kof99/garou) lecture de protection + générateur pseudo-aléatoire. Le modèle à suivre est mslug3 (`mslug3_decrypt_68k`, `mslug3_bank_base`, port `Sma3`).

| jeu | déchiffrement P (prot_sma.cpp) | gfx | M1 | banc fixe | runtime |
|---|---|---|---|---|---|
| kof99 | `kof99_decrypt_68k` | CMC42 clé 0x00 + sfix | clair | Garou (1) | kof99_bankswitch_w, kof99_bank_base, prot_9a37_r, random_r |
| garou | `garou_decrypt_68k` | CMC42 clé 0x06 + sfix | clair | Garou (1) | garou_bankswitch_w, garou_bank_base, prot_9a37_r, random_r |
| kof2000 | `kof2000_decrypt_68k` | CMC50 clé 0x00 + sfix, M1 chiffrée (`m1_decrypt`) | chiffrée | Kof2000 (2) | kof2000_bankswitch_w, kof2000_bank_base, prot_9a37_r, random_r |

- `PDecrypt` gagne `Kof99, Garou, Kof2000` ; `RuntimeProt` gagne `Sma99, SmaGarou, Sma2000` (garder `Sma3`). Les fonctions sont des portages **exacts** de `prot_sma.cpp` (mêmes tables, mêmes bitswaps) dans `sma.rs` ; les ports (`impl CartPort`) dans `prot_sma.rs` ; `make_port` instancie le bon.
- Ordre de `decrypt_all` : P (déchiffrement du jeu), puis M1 (kof2000), gfx, sfix.
- Les adresses d'accès ($2FFFF0-$2FFFFF banc, lectures de protection) sont celles de `sma.cpp`/`prot_sma.cpp` ; la priorité du port sur le banc standard est déjà en place (T710).
