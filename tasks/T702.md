## Spécification (décidée, ne pas réinterpréter)
`pub struct MslugX { command:u16, counter:u16 }` implémente `CartPort` : actif UNIQUEMENT pour `0x2FFFE0 <= a <= 0x2FFFEF` (sinon `read` => None, `write` => false). Offset de mot `o = (a - 0x2FFFE0) >> 1`.
Écriture (`protection_w`) : `o==0` : command=0 ; `o==1 || o==2` : command |= data ; `o==3` : rien ; `o==5` : counter=0, command=0 ; autres : rien. Retourne true (consommée).
Lecture (`protection_r`) : selon `command` : `0x0001` : `res = (p_byte(0xDEDD2 + ((counter>>3)&0xFFF)) >> (!counter & 7)) & 1` puis `counter += 1` ; `0x0FFF` : `select = (word_ram(0x10F00A) as i32) - 1` ; `res = (p_byte(0xDEDD2 + ((select>>3)&0xFFF)) >> (!select & 7)) & 1` (décalage arithmétique i32) ; autre : 0. `p_byte(x)` = `p[x]` (P ROM, bank 0 : adresse < 0x100000, donc index direct dans `p`) ; `word_ram(0x10F00A)` = mot BE de `wram[0x0F00A..]`. Retourner `Some(res as u16)`.
