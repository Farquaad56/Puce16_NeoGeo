## Spécification (décidée, ne pas réinterpréter)
Rendre les tables de `input.rs` configurables. (1) Modèle : `enum Action { P1Up, P1Down, P1Left, P1Right, P1A, P1B, P1C, P1D, P2Up, …, P2D, Start1, Start2, Select1, Select2, Coin1, Coin2, Service, Test }` avec `Action::ALL`, `label()` français (« J1 Haut »…) et `default_key()` (valeurs actuelles de T801b). `pub struct Bindings { keys: HashMap<Action, egui::Key>, pad: HashMap<Action, gilrs::Button> }` ; `Bindings::default()`, `key_name(Key)->String` / `parse_key(&str)->Option<Key>` (utiliser `egui::Key::name()` et `Key::from_name`), `from_prefs(&InputPrefs)->Bindings` (action inconnue ou touche invalide ignorées, défaut conservé), `to_prefs(&self)->InputPrefs`. `InputState` utilise `Bindings` au lieu des tables constantes (`InputState::with_bindings`). (2) Fenêtre « Contrôles » (menu Émulation > Contrôles…) : tableau Action / Touche / Manette ; clic sur une case = mode capture (« Appuyez sur une touche… », Échap annule) ; la touche pressée est assignée ; si elle est déjà prise par une autre action, **échange** des deux assignations ; boutons « Valeurs par défaut » (toutes ou par joueur). Capture manette : prochain bouton gilrs pressé. (3) Persistance : toute modification met à jour `Prefs.input` et déclenche la sauvegarde de `gui.toml` (T804a). Au démarrage, `Bindings::from_prefs`. Pas de SOCD cleaning (inchangé).
