## Spécification (décidée, ne pas réinterpréter)
`impl Cart { pub fn decrypt_all(&mut self) }` : exécuter, dans CET ordre exact (MAME `decrypt_all`), selon `self.def.prot` :
- MS3 (`Sma3`) : `mslug3_decrypt_68k(&mut p)` ; `cmc42_gfx_decrypt(&mut c, key)` ; `sfix_decrypt(&c, &mut s)`.
- MS4 (`Cmc::C50`, `Pcm2::Decrypt(8)`) : `cmc50_m1_decrypt(&mut m_crypt, &mut m)` ; `cmc50_gfx_decrypt(&mut c, key)` ; `sfix_decrypt(&c, &mut s)` ; `pcm2_decrypt(&mut v, 8)`.
- MS5 : `mslug5_decrypt_68k(&mut p)` ; `pcm2_swap(&mut v, 2)` ; `cmc50_m1_decrypt` ; `cmc50_gfx_decrypt(key)` ; `sfix_decrypt`.
- MSLUG, MSLUG2, MSLUGX : rien.
`pub fn make_port(&self) -> Option<Box<dyn CartPort>>` : `RuntimeProt::Msx => MslugX::new()`, `Sma3 => Sma3::new()`, `Pvc => Pvc::new()`, `None => None`. Remplacer le stub de `load_machine` (T600c) : `cart.decrypt_all(); bus.port = cart.make_port();`. Les tailles de `s` : `sizes.s` (S de 0x20000 pour MS3/4/5 rempli par sfix_decrypt) ; `m` pour MS4/5 : `sizes.m` >= 0x90000.
